# Проект «Blog Customizer»

> Учебный проект, выполненный в рамках курса «Фронтенд-разработчик» от Яндекс Практикума по управлению состоянием и взаимодействию компонентов в React.

### Задача проекта:
- Собрать форму настройки оформления статьи из готовых UI-компонентов.
- Реализовать открытие и закрытие боковой панели.
- Разделить состояние формы и применённые настройки страницы.
- Настроить применение и сброс оформления через CSS-переменные.

## Описание проекта
**«Blog Customizer»** — интерактивное React-приложение для настройки внешнего вида статьи: шрифтов, цветовой палитры и ширины контента. Пользователь выбирает параметры в боковой панели и применяет их к странице или возвращается к исходному оформлению.

Вёрстка и UI-компоненты предоставлены в заготовке. Моя работа — сборка формы, управление состоянием и передача данных между компонентами.

## Реализовала:
- Собрала форму `ArticleParamsForm` из готовых компонентов выбора шрифта, размера текста, цветов и ширины контента.
- Добавила состояние видимости панели и обработчик кнопки-стрелки.
- Подключила закрытие панели по клику за её пределами через готовый хук.
- Организовала отдельное хранение выбранных значений формы и применённых настроек статьи с помощью `useState`.
- Создала общий обработчик изменения полей формы.
- Настроила передачу параметров из формы в `App` через типизированные props и callback-функции.
- Реализовала обновление CSS-переменных статьи по кнопке «Применить».
- Добавила сброс значений формы и оформления страницы к начальным настройкам.

## Результат:
- Научилась дополнять готовые React-компоненты состояниями и обработчиками событий.
- Разобралась, как выбирать место хранения состояния и передавать данные между родительским и дочерним компонентами.
- Освоила разделение редактируемых и применённых настроек, чтобы изменения вступали в силу только после подтверждения.
- Закрепила работу с управляемыми полями формы и обновлением объектов в состоянии React.
- Получила опыт типизации props и обработчиков на TypeScript.
- Научилась связывать состояние приложения с оформлением через CSS-переменные.

├── postcss.config.js            # настройки обработки CSS

├── package.json                 # зависимости и команды

## Запуск

1. В каталоге проекта установите зависимости:

```bash
npm ci
```

2. Запустите приложение:

```bash
npm start
```

## Полезные команды

| Команда | Назначение |
| --- | --- |
| `npm start` | запуск сервера разработки |
| `npm run build` | сборка приложения в каталог `dist` |
| `npm run storybook` | запуск Storybook на порту 6006 |
| `npm run build-storybook` | сборка Storybook |
| `npm run stylelint` | проверка SCSS-стилей |
| `npm run stylelint:fix` | автоматическое исправление ошибок в стилях |
| `npm run lint` | проверка и автоматическое исправление кода |
| `npm run format` | форматирование исходных файлов |
| `npm test` | последовательный запуск исправления стилей, линтера и форматирования |

Команда `npm test` в этом проекте запускает инструменты качества кода и изменяет файлы. Модульные и браузерные тесты этой командой не выполняются.
